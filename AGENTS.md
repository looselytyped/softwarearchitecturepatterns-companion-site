# Repository Guidelines

## Commits

- Always use the [Conventional Commits](https://www.conventionalcommits.org/) specification for commit messages.
- Use the format `<type>(<optional scope>): <description>`, for example: `feat: add book catalog`.
- Choose a type that accurately describes the change, such as `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, or `chore`.
